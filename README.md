# README
This was originally inteded to be an STB style header library, but I just couldn't stick to it, so it was seperated into a few headers, some that depend on others. This works for my personal workflow better than a single monolithic file while still allowing you to patch them together yourself if you want to. I may one day make a simple script that packages them together and adds them to this repo as well but as of OCT/21/26 I have no real intention of doing that.

## Disclaimer
None of this code is set in stone and is subject to large changes as I build out other systems.
